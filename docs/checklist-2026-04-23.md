### 🗄️ База данных
- [x] `users` — профиль, роль (renter/owner/admin), рейтинг, completed_deals_count

### 💰 Финансовая модель (Dual Shield v2 + Free)
- [x] Premium: serviceFee 10% + taxFee 6% + shieldFee 5% (min 100₽) + riskCoverage 5% (min 100₽)
- [x] **Free: 0% удержаний — владелец получает всю сумму**
- [x] Залог: `max(depositMin, pricePerDay × depositMultiplier)` (Premium) / опционально (Free)
- [x] Лимиты защиты по категориям: электроника ×50 / инструменты ×20 / отдых ×15 / спецтехника ×10
- [x] Кап для новых пользователей (до 3 сделок — max 25 000 ₽)
- [x] Все ставки читаются из БД через кэш (меняются из админки, TTL 60с)
- [x] Client `utils.ts` — все расчётные функции принимают `FeeRates` override
