Action 1: Database & Migrations (schema.ts & Drizzle)

Add a new column to the claims table: aiVerdict: jsonb('ai_verdict').

Run pnpm db:push to apply the change.

Action 2: Backend AI Service (artifacts/api-server/src/lib/ai-service.ts)

Create an isolated function: arbitrateWithGeminiVision(claimId: number).

Data fetching explicitly: Get digital_acts where type='check_in' and type='check_out' matching the claim's booking_id. If it's a pool claim, use type='pool_handover'. If missing or < 2 photos, return { confidence: "low", error: "Not enough photos" }.

Convert images to base64 inlineData (image/jpeg or image/png).

Model & Timeout: Use gemini-1.5-flash for vision. Wrap the fetch call in a 15-second timeout (using AbortController) to prevent hanging requests.

Prompt constraint: Instruct the AI to act as an impartial judge and output STRICT JSON:
{ "faultEstimatePercent": number, "confidence": "low"|"medium"|"high", "verdictDraft": "string", "evidenceCitations": ["string"] }. Do NOT ask the AI to calculate the exact monetary amount.

Fallback: Wrap in try/catch. On API failure or timeout, return { confidence: "low", error: "AI service unavailable or timed out" }.

Action 3: Backend Endpoint (artifacts/api-server/src/routes/claims.ts)

Create POST /api/claims/:id/ai-verdict (wrapped in requireAdmin).

Caching: Check if claim.aiVerdict exists in DB. If yes, return it immediately.

If no, call arbitrateWithGeminiVision. Calculate suggestedAmountRub = requestedAmount * (faultEstimatePercent / 100) inside the route using TypeScript. Add this amount to the final JSON.

Update the claims table to save this JSON into the ai_verdict column.

Audit: Log the action to audit_events (eventType: 'ai_verdict_requested').
