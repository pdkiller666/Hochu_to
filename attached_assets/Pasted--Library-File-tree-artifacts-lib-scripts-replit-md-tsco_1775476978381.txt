Создай WordPress сайт «Хочу_То» — маркетплейс арендыWordPress вещей и долевых покупок. Регион: возможность выбора города/региона (Россия, масштабирование). Сайт адаптивный, современный, с фундаментом для мультивендорности.

Структура:

Главная: баннер, популярные категории (стройка, туризм, сад, праздники, дети, электроника), как работает, преимущества, отзывы.

Каталог: фильтры (категории, цена, регион), поиск, карточки товаров (фото, название, цена за сутки, кнопка).

Страница товара: галерея, описание, цена, календарь выбора периода (произвольные даты), форма бронирования, контакты владельца после бронирования.

Регистрация/вход (роли: арендатор, владелец).

Личный кабинет: заказы, мои вещи (добавление/редактирование), настройки профиля.

Долевые покупки: описание + форма заявки.

Инструкции: как арендовать, как сдать, гарантийный фонд (система взаимопомощи).

О нас, контакты, политика конфиденциальности.

Визуал: цвета #C65D3B (основной), #F2EEE3 (фон), #4A8587 (акцент), #2B2B2B (текст). Шрифты Montserrat (заголовки), Inter (текст). Стиль: дружелюбный, тёплый, современный. Элементы: мягкие тени, скругления, адаптив.

Функционал:

Выбор региона (город) при регистрации/в каталоге.

Регистрация пользователей с возможностью добавлять вещи (в будущем – мультивендор).

Календарь бронирования с произвольным периодом, аналогичный по возможностям как у сервиса Bukza

Формы: бронирования, подачи объявления, обратной связи.

Интеграции: ссылки на соцсети (VK, Telegram), подписка на новости.

SEO: ЧПУ, метатеги.

Масштабируемость: база на WordPress с возможностью добавления плагинов для мультивендорности (Dokan), бронирований (MotoPress), оплаты. Код чистый, без жёсткой привязки.

Требования к вёрстке: шапка с логотипом, меню, кнопки входа/регистрации, выбор региона; подвал с контактами, меню, подпиской. Все страницы созданы, меню настроено.
