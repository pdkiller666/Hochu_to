Промпт для агента: Stage 42 – Полностью генеративная инфографика (OpenRouter → Gemini → SVG fallback)

Task: Stage 42 – Pivot to Full AI-Generative Product Cards with OpenRouter Primary + Gemini Direct Fallback

Context:
Агент предоставил отчёт current_infographic_analysis.md. В текущей реализации генеративный пайплайн (Tier 1 – OpenRouter, Tier 2 – Gemini) недоступен из-за отсутствия платных ключей, поэтому всегда срабатывает Tier 2.5 – SVG overlay.
Пользователь хочет перейти на полностью генеративные карточки (как на примере с мангалом), используя:

· Primary: OpenRouter API с перебором моделей для генерации изображений (DALL‑E 3, Flux Pro и др.)
· Fallback: Прямой Gemini API (Imagen 3) – уже есть ключ
· Последний fallback: Существующий SVG overlay (Tier 2.5) – для отказоустойчивости

Цель:
Реализовать надёжный image‑to‑image пайплайн, который генерирует готовую карточку (фото товара + наложенный текст и брендинг) с помощью AI, с автоматическим переключением между провайдерами и кэшированием результатов.

---

🚨 Критические правила безопасности

· Не удалять старый код buildMarketplaceInfographic и buildMarketplaceOverlaySvg – они остаются как Tier 3 fallback.
· Не изменять существующие эндпоинты и формат ответа API (клиент ожидает {url, generativeTier, content, ...}).
· Все новые функции должны логировать ошибки через logger (pino) и писать в audit_events при успешной генерации (eventType ai_image_generation).
· При отсутствии OPENROUTER_API_KEY система должна автоматически переходить на Gemini, затем на SVG overlay – без крашей.

2. Убрать заглушку // Tier 1/2 недоступны на бесплатном плане – сразу используем SVG (строки 294-296 в routes/ai.ts перенести логику выбора в infographic.ts).
3. В generateGenerativeInfographic реализовать следующую логику:
   ```typescript
   export async function generateGenerativeInfographic(imageBuffer: Buffer, content: MarketplaceInfographicContent, options?: { format?: "square" | "horizontal", preprocess?: boolean }): Promise<{ image: Buffer; tier: 1 | 2 | 3; provider: string }> {
     // 1. Предобработка фото (если preprocess === true)
     let processedPhoto = imageBuffer;
     if (options?.preprocess) processedPhoto = await preprocessForAI(imageBuffer);
     
     // 2. Сформировать промпт (использовать существующий buildImagePrompt, добавив параметр формата)
     const prompt = buildImagePrompt({ ...content, format: options?.format });
     
     // 3. Tier 1 – OpenRouter (перебор моделей)
     const orResult = await tryOpenRouter(processedPhoto, prompt, options?.format);
     if (orResult.image) return { image: orResult.image, tier: 1, provider: orResult.provider };
     
     // 4. Tier 2 – Gemini Imagen 3 (прямой API)
     const geminiResult = await tryGeminiImageGen(processedPhoto, prompt, options?.format);
     if (geminiResult.image) return { image: geminiResult.image, tier: 2, provider: "gemini" };
     
     // 5. Tier 3 – старый SVG overlay (с использованием существующего buildMarketplaceInfographic)
     const fallbackImage = await buildMarketplaceInfographic(imageBuffer, content, { format: options?.format });
     return { image: fallbackImage, tier: 3, provider: "svg-overlay" };
   }
   ```

  ```typescript
  function fitTextToWidth(text: string, maxChars: number, baseFontSize: number): { text: string; fontSize: number } {
    if (text.length <= maxChars) return { text, fontSize: baseFontSize };
    let newSize = baseFontSize;
    let truncated = text;
    while (newSize > 12 && truncated.length > maxChars) {
      newSize -= 2;
      truncated = text.slice(0, maxChars * (newSize / baseFontSize)) + "…";
    }
    return { text: truncated, fontSize: newSize };
  }
  ```
